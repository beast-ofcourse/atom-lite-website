## Direction contract

THESIS: The homepage is an open card catalog of resumable sessions, not a hero-with-bullets page. The install command is a stamped call number on the front card — the action is the artifact. The category default (dark gradient hero around a floating terminal mockup, feature cards below) is refused.

OWN-WORLD: Kraft manila is the ground and the card stock; deep charcoal ink carries every word; one signal-red rubber stamp marks only the active card. Tab dividers, dates, and commands use a mono with real character; headings use a self-hosted display grotesk at heavy weight. Remove all content and the language is still recognizable: overlapping ruled cards, notched tab dividers, circular date stamps, a stamped slip.

STORY: The visitor sees a working archive of local sessions, understands the tiny-core/extensible mechanism, and copies the install command from the front card before scrolling.

FIRST VIEWPORT: Slim top bar — atom-orbit mark and atom-lite wordmark left, quiet Docs / GitHub links right. Centre-left, one oversized kraft index card holds the name, the one-line pitch, the install command on a visibly copyable ruled strip with a copy control, the npx alternative, and the red active stamp. Behind and to the right, a fanned drawer of session cards under tab dividers labelled Today / Previous 7 days / By workspace; two cards carry the real web UI captures and one a play affordance for the TUI demo. A low strip names the ten tools as mono labels. The primary action sits centre-left at eye level, unmistakable.

FORM: Committed world — The Session Drawer, position 5 of the grounded list. seed: e2dfd592f8ec86c5.
